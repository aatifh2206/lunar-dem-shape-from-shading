# Lunar DEM Reconstruction using Shape-from-Shading

This repository contains my Python implementation of a lunar Digital Elevation Model (DEM) reconstruction workflow, developed during the ISRO Bharatiya Antariksh Hackathon 2025.

The project uses Shape-from-Shading (SFS) to estimate lunar surface gradients from a single image and reconstruct an initial relative-height surface. It uses the Gauss-Seidel method for gradient estimation and Frankot-Chellappa integration to recover the surface.

The repository also contains code for calibrating the reconstructed DEM using reference elevation data and comparing terrain profiles.

## Method

The workflow consists of the following steps:

1. **Image preparation:** Load the lunar image and normalize its intensity values.
2. **Gradient estimation:** Estimate surface gradients using the Shape-from-Shading approach and the Gauss-Seidel method.
3. **DEM reconstruction:** Integrate the estimated gradients using the Frankot-Chellappa method to obtain an initial relative-height surface.
4. **Surface detrending:** Remove a fitted plane to inspect the local terrain shape.
5. **3D visualization:** Visualize the reconstructed surface using Matplotlib and Plotly.
6. **DEM calibration:** Fit a linear relationship between the reconstructed surface and a reference DEM.
7. **Profile comparison:** Compare terrain profiles from the initial DEM, reference DEM and calibrated DEM.

## Repository Structure

- `01_shape_from_shading.ipynb`: Image preparation, gradient estimation, DEM reconstruction, detrending and 3D visualization.
- `02_dem_calibration.ipynb`: Calibration of the reconstructed DEM using reference elevation data.
- `03_dem_profile_comparison.ipynb`: Interactive selection and comparison of terrain profiles.
- `try.png`: Example input image used by the SFS notebook.
- `requirements.txt`: Python packages required to run the notebooks.

## Requirements

Python 3 and the packages listed in `requirements.txt` are required.

Install the packages using:

```bash
pip install -r requirements.txt
```

## How to Run

1. Clone or download this repository.
2. Install the required Python packages.
3. Open `01_shape_from_shading.ipynb` and run the cells in order to reconstruct the initial relative-height surface.
4. To use `02_dem_calibration.ipynb`, provide a suitable reference DEM and prepare it so that it is spatially aligned with the reconstructed DEM.
5. To use `03_dem_profile_comparison.ipynb`, provide the initial DEM, reference DEM and calibrated DEM generated by the preceding steps.

The calibration and profile-comparison notebooks require additional data that are not currently provided as a ready-to-use dataset in this repository.

## Data Requirements

The SFS notebook uses the included `try.png` image. The calibration and profile-comparison stages require a reference DEM covering the same terrain region as the input image.

The reference DEM must be correctly co-registered with the reconstructed DEM. Matching image dimensions alone does not guarantee that the pixels represent the same terrain locations.

Users must provide and prepare compatible reference elevation data before running the calibration and profile-comparison stages.

## Limitations

- Shape-from-Shading depends on assumptions about surface reflectance and illumination.
- The reconstructed surface initially represents relative height rather than independently verified absolute elevation.
- Calibration depends on the quality and spatial alignment of the reference DEM.
- The code has not been validated here against a complete, aligned reference dataset.
- Results may depend on the selected illumination vector and algorithm parameters.
